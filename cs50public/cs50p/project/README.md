 Project title: Speedtyping.py/Speedtyping test
 Video URL: https://youtu.be/jvKcKTVWBSM

Made using python by twilightshield109 and finalized on 28/7/2025.

Many functionalities of this speed typing test requires imported libraries such as the measurement of time as well as the cosmetics (colours of text). Libary "faker" is used to generate the random words in a straightforward and easy way (I'm thinking of using a vocabulary list myself for later to get more organized ones). Library "time" is used here to get the exact time to miliseconds. Library "sys" is only used in one line - Faker generates text in multiple lines, so this ensures the user will not run into issues trying to skip a line when only a space is required.

 This speedtyping test will generate random words (with random titlecased words along the way to add an extra layer of challenge) and test your speed as well as your accuracy in typing (listed as a percentage). Correctly typed words will be highlighted in green while words with typos will be highlighted in red. You will be given a small note of comment depending on how fast and accurate you type. Data in numbers is highlighted in blue for easier access.

This project is for leisure purposes. In the future, I will attempt to let the program generate actual pieces of coherent text/words in the same category (fruits, animals) instead of purely random words, as well as a gamemode incorporating a time limit to the test. This was one of my goals before, but it was not executed due to troubles in incorporating the test and the timer together simultaneously. A feature recording your best run might also be implemented.

Thank you and enjoy using this test to challenge yourselves! :D
